## 十八、不含标音版专属规则

本版本的答案、翻译、考点和解析必须与含标音版使用同一内容数据库。两个版本不得分别求答案或分别改写解析；唯一差异是本版本不生成任何新增读音层，也不为Ruby额外调整行距。

### 1. 字体和字号

- 所有日文正文，包括日汉字、平假名、片假名、日文标点及日文语境中的数字和拉丁字母：MS Mincho，11磅；
- 所有中文正文，包括中文标题、翻译、考点、解析、题源信息及日文中的中文释义：宋体，11磅；
- 中日文混排必须根据语言功能拆分运行块；
- 不得因取消标音而放松字体和语言属性审计。

### 2. 全文禁止新增Ruby

最终文档中禁止：

- 新建Word原生<w:ruby>节点；
- 使用Word拼音指南添加读音；
- 使用普通上标模拟假名；
- 在汉字后自动添加括号读音；
- 使用文本框、空格、双行文本或图片模拟读音；
- 把假名单独放在汉字上一行；
- 在解析中为日文词语额外补充未经原题要求的读音。

### 3. 原题自带标音的处理

按照参数【是否保留原题自带标音】执行：

- 选择“是”：原题中本来就属于题目内容、考查内容或作者明确保留的读音原样保留，但系统不得新增其他读音；
- 选择“否”：移除旧文档中由系统附加的Ruby、普通上标和括号标音，同时保留题干原本的日文汉字、假名和文字内容；
- 无法判断某一读音是否属于原题时，回到题目母本核对，不得直接删除或保留。

### 4. 版本内容一致性

不含标音版必须与含标音版满足：

- 题目数量一致；
- 题号和章节一致；
- 答案一致；
- 完整日文一致；
- 中文翻译一致；
- 考点一致；
- 解析和错误项排除一致；
- 阅读定位证据一致；
- 答案汇总一致；
- 红字和批注范围一致。

禁止为了删除标音重新分词、重写句子或改变字符顺序。

### 5. 清除旧标音残留

审核旧Word时，检查并清除不应存在的：

- w:ruby、w:rubyBase和w:rt节点；
- 普通上标假名；
- 浮动文本框假名；
- 汉字后的自动括号读音；
- 标音造成的异常空格、异常制表符和软换行；
- 标音专用字符样式；
- 标音造成的过大行距和页数膨胀。

清除后必须保证正文基底字符与题目、答案数据库完全一致。

### 6. 行距与版式

- 日文和中文正文使用项目统一的正常行距；
- 不为不存在的Ruby预留上方空间；
- 标题、目录、答案汇总、逐题解析的行距分级设置；
- 不使用分散对齐造成异常字符间距；
- 字符缩放100%，字符间距0磅，位置标准；
- 删除因旧标音遗留的空白行和异常分页。

### 7. 不含标音版专项审计

交付前逐项确认：

- 日文正文MS Mincho 11磅；
- 中文正文宋体11磅；
- Word原生Ruby节点：0；
- 普通上标模拟读音：0；
- 文本框或空格模拟读音：0；
- 系统新增括号读音：0；
- 标音专用异常行距：0；
- 中文误用MS Mincho：0；
- 日文假名或日汉字误用宋体：0；
- 删除标音后正文丢字、增字、倒序或异常空格：0；
- 题目、答案和解析与含标音内容数据库不一致：0。
