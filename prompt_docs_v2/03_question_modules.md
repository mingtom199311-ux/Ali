## 九、高考日语各题型专项解析要求

### 1. 语法、词汇、形容词、副词和句型单选

重点核对：

- 接续形式是否成立；
- 词义是否符合当前语境；
- 时态、肯否、语体是否一致；
- 副词与句末形式是否形成固定呼应；
- 句型的使用限制和语气是否合适；
- 外形相似或意义相近的干扰项为何不能替换。

副词题尤其检查：程度、频率、时间、状态、陈述语气，以及「決して～ない」「たぶん～だろう／でしょう」「ぜひ～たい／てください」「たとえ～ても」等呼应关系。

句型题尤其检查：前接形式、后项限制、主观／客观语气、书面／口语语域及与易混句型的最小差异。

### 2. 助词和连词

助词解析必须明确：

- 动作场所、存在场所、到达点、经过场所、离开场所；
- 动作对象、给予者、接受者、施动者、使役对象；
- 原因、手段、材料、范围、比较基准、变化结果；
- 主格、宾格、领格、引用、并列、限定、强调；
- 固定搭配与复合助词。

连词解析必须先确定前后句关系：

- 顺承、并列、递进；
- 因果、结果；
- 一般转折、预想外转折；
- 换言、总结；
- 选择；
- 话题转换；
- 补充说明。

不得只依据中文大意判断连词，必须说明前项和后项在语篇中的具体逻辑。

### 3. 动词活用

必须写清：

- 一类、二类、三类动词或特殊动词；
- 原形到目标形式的逐步变化；
- 现在／过去、肯定／否定、简体／礼貌体；
- 可能、被动、使役、使役被动、意志、命令等功能；
- 题干中哪一项线索锁定该形式；
- 横线后是否已经保留部分后缀。

不得把“第一连用形”“て形”“た形”“意志形”等概念混写。敬语中的“ます形去掉ます后的部分”统一称为“动词第一连用形”。

### 4. 补助动词

逐题区分：

- 「V-ている」动作进行、反复习惯、结果状态；
- 「V-てある」人为动作完成后的结果状态；
- 「V-ておく」事先准备、保持状态；
- 「V-てしまう」动作完成、遗憾或不良结果；
- 「V-てみる」尝试；
- 「V-ていく／くる」空间方向、时间变化和状态发展；
- 口语约音及其原形。

解析必须结合自动词／他动词和语境，不能只看到外形就套用固定释义。

### 5. 授受动词

先画清内部关系，再写解析：

- 动作由谁发出；
- 谁是受益者；
- 谁属于说话人一方；
- 使用「あげる／やる／くれる／もらう」及其敬语形式的理由；
- 「に／から／を」等助词的具体功能；
- 事物作为施益主体时是否具有明确的积极效果。

不得把“别人为我方做”与“我方请别人做”混为一谈。

### 6. 复合动词

必须识别：

- 前项动词第一连用形；
- 后项复合成分的核心意义；
- 开始、持续、完成、中断、过度、尝试、难易、可能等具体功能；
- 是否属于固定词汇而非临时组合；
- 与补助动词或普通连用修饰的区别。

### 7. 假定、样态和推测

假定题必须区分：

- 「と」自然规律、必然结果、机械操作、习惯；
- 「ば」一般条件、规律和书面表达；
- 「たら」个别假设、已然条件、契机；
- 「なら」承接话题、提出建议；
- 「ては／では」消极条件或反复。

样态推测题必须区分：

- 样态「そうだ」；
- 传闻「そうだ」；
- 比况／推测「ようだ」「みたいだ」；
- 推测／典型性「らしい」；
- 否定形式、接续和特殊变化。

### 8. 名词、指示代词和形式名词

指示代词题必须判断：

- 现场距离；
- 说话人与听话人掌握的信息；
- 文章中的前指、后指；
- 双方已知、单方已知、未知和疑问；
- 指人、指物、指地点、指程度、指时间或承接话题。

形式名词题必须说明：

- 前接形式；
- 名词化、原因、预定、范围、状态、依据等具体功能；
- 与相似形式名词的差异；
- 是否构成固定句型。

### 9. 形容词

必须确认：

- 一类形容词或二类形容词；
- 基本形、过去、否定、过去否定、中顿、定语、连用、假定；
- 「いい／よい」「同じ」「きれい」「嫌い」等特殊词；
- 后接「なる／する／そうだ」时的准确变化；
- 形容词与名词、动词或副词的修饰关系。

### 10. 敬语与交际用语

解析前先确认：

- 动作主体是谁；
- 尊敬对象是谁；
- 主语属于说话人一方还是对方；
- 应使用尊他、自谦、郑重或一般礼貌表达；
- 交际场景、身份关系和语气是否得体；
- 是否存在对自己使用尊他语、对尊长使用自谦主体错误等问题。

一般敬语句型统一表述为：

- 「お＋动词第一连用形＋になる／なさる／です」；
- 「ご＋三类动词词干＋になる／なさる／です」；
- 「お＋动词第一连用形＋する／いたす／申し上げる」；
- 「ご＋三类动词词干＋する／いたす／申し上げる」。

同时优先核查特殊敬语动词及其固定形式。

### 11. 量词、数字和读音题

必须说明：

- 被计数对象；
- 正确量词；
- 数字与量词的组合；
- 促音、浊音、半浊音和连浊；
- 日期、时间、人数、楼层等特殊读音；
- 其他读音为什么不成立。

不能只给出读音而不解释音变规则，也不能用单字最常见读音替代当前词语的实际读音。

## 十、阅读理解专项规则

### 1. 先建立文章结构

阅读全文后，先在内部确定：

- 文章主题；
- 各段功能；
- 主要人物和观点归属；
- 时间推进；
- 转折、因果、举例和结论；
- 指示词、代词和省略成分的指向；
- 作者态度与最终结论。

不得看完题目选项后反向拼凑文章主旨。

### 2. 不同阅读题型的证据标准

| 阅读题型 | 必须完成的证据链 |
|---|---|
| 细节理解 | 定位原句，说明题干／正确项与原文的同义改写；逐项核对主体、对象、时间和数量。 |
| 指代题 | 找到指示词、代词或省略成分，确定完整指代范围；不能只写前一个名词。 |
| 原因／目的题 | 区分直接原因、背景原因、结果和目的；指出连接词或因果句。 |
| 主旨题 | 概括各段功能，提取全文反复出现的核心，不得用局部例子代替主旨。 |
| 标题题 | 标题必须覆盖全文主题和作者重点，不能只对应某一段细节。 |
| 推断题 | 明确原文事实、必要推理步骤和推断边界；不得过度推断。 |
| 作者态度题 | 根据评价词、语气副词、转折和结论判断，并区分作者与引用人物的观点。 |
| 句子插入题 | 检查指代、连词、新旧信息、时间顺序和段落衔接。 |
| 段落排序题 | 检查首次提出、指代回收、例证展开、转折和总结的逻辑顺序。 |
| 内容一致题 | 每个选项都回到原文逐项核对，不依赖常识猜测。 |

### 3. 阅读干扰项分类

排除错误项时指出其具体类型：

- 主体偷换；
- 对象偷换；
- 时间范围改变；
- 数量或程度改变；
- 原因与结果倒置；
- 条件与结论倒置；
- 局部信息扩大为全文；
- “可能”扩大为“一定”；
- 作者观点偷换成他人观点；
- 例子误当主旨；
- 原文未提及；
- 与原文相反。

### 4. 阅读翻译

当【阅读翻译范围】为“全文翻译”时：

- 按原文段落翻译；
- 保留人物关系、逻辑和语气；
- 不随意增删信息；
- 专有名词、引用和数字准确对应；
- 翻译完成后再逐题解析。

当为“重点句翻译”时，只翻译定位句及理解答案所必需的上下文；当为“仅解析”时，也必须在内部完成文章理解，不得省略证据链。

## 十一、语篇完形专项规则

逐篇先建立“主题—段落功能—人物—时间—逻辑—指代”框架，再分析每个空。

每空至少检查：

- 词性和接续；
- 句内固定搭配；
- 前后句逻辑；
- 该词在全文中的指代；
- 时态、人称和语体；
- 作者立场；
- 同一词在上下文中的复现或同义替换。

正确答案必须同时满足局部语法和全文逻辑。局部能成立但破坏全文关系的选项必须排除。

## 十二、反幻觉与可追溯机制

### 1. 原题实体一致性

解析中的人物、时间、地点、数量、动作、对象、肯否、因果和态度必须能够在题目、文章、选项或指定资料中找到直接依据。

任何原题不存在的实体或情节一旦出现，整题解析立即判定不合格并重做。

### 2. 完整日文不可改写

完整日文只能由题干原文和审核答案合成。除非【题目状态】明确允许修题，否则不得改变任何题干字符。

### 3. 证据必须可追溯

- 语法题：证据为接续、变形、固定搭配、句末呼应或语境；
- 语篇题：证据为前后段逻辑、指代、时态和文章结构；
- 阅读题：证据为原文定位、同义改写或必要推理；
- 敬语题：证据为动作主体、尊敬对象和场景关系；
- 量词读音题：证据为计数对象和音变规则。

### 4. 禁止反向编造

不得执行以下流程：

旧答案是什么 → 假设题干大概表达某意思 → 编写一个看似合理的解析。

必须执行：

读取冻结题目 → 独立作答 → 验证唯一性 → 生成完整日文 → 翻译 → 考点 → 解析 → 与旧稿比较。

### 5. 未解决问题阻断交付

若仍存在下列情况，不得用含糊措辞假装完成：

- 两个答案均自然且无权威依据；
- 题干或选项残缺；
- 阅读文章缺段；
- 题号错位无法恢复；
- 官方题源无法对应；
- 读音或专有名词无法可靠确认。

先解决材料问题，再生成最终成品。
